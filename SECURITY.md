# Security Policy

## Supported versions

Security fixes are considered for the latest code on the repository's default branch. No older releases or versions are supported.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

Use GitHub's private vulnerability reporting feature for this repository. If private reporting is unavailable, open an issue asking for a private reporting contact without including vulnerability details.

Include a summary of the issue, its potential impact, the affected commit or release, and steps or a proof of concept to reproduce it. For deployment-specific reports, include relevant configuration details with secrets removed.

Do not include real passwords, password-derived tokens, secret links or link fragments, client keys, revocation tokens, plaintext content, or other users' data in a report.

## Coordinated disclosure

Please allow time to investigate and address a report before publicly disclosing it. We will coordinate disclosure timing with the reporter. We may ask for additional information to reproduce or assess the issue.
