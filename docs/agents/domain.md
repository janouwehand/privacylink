# Domain Documentation

This repository uses a single-context domain documentation layout. Write new domain documentation in English by default; existing documents may remain in their original language unless they need revision.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant decisions in `docs/adr/` when they exist.
- If these files do not exist, proceed without treating their absence as a blocker.

## Domain vocabulary

Use established terms from `CONTEXT.md` when available. In this repository, the current product vocabulary includes `secret`, `sender history`, `share link`, `client key`, and `revoke token`.

## Architectural decisions

If a proposed change conflicts with a relevant ADR, identify the conflict and explain why the decision may need to be revisited.
