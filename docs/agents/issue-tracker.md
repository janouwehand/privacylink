# Issue Tracker: GitHub

Issues and specifications for this repository are written in English and live in GitHub Issues. Use the GitHub CLI or the connected GitHub issue tools for tracker operations.

## Conventions

- Create issues in English with a clear title and complete Markdown body, unless the user explicitly requests another language.
- Read an issue with its comments and labels before acting on it.
- Apply the repository's triage labels where a skill requests them.
- Pull requests are not a request intake surface.

## When a skill says “publish to the issue tracker”

Create an English-language GitHub issue in `janouwehand/privacylink`, unless the user explicitly requests another language.

## When a skill says “fetch the relevant ticket”

Read the GitHub issue and its comments in `janouwehand/privacylink`.
